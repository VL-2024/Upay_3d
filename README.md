# УПАЙ v0.1.1-alpha — технический прототип

Первый рабочий прототип по ТЗ X2 LOTO.

## Реализовано

- Babylon.js + Havok Physics
- вертикальная mobile-first сцена
- 15 тестовых чүкө + 1 Хан
- физическое рассыпание и ожидание стабилизации
- 4 технических положения: AYKUR / TAA / CHIK / BOK
- валидатор раскладки и автоматический reroll
- выбор чүкө и подсветка допустимых целей
- tap-to-target и swipe-to-target
- физический щелчок
- debug-метки и FPS
- заготовка сценарного движка ZERO / ONE / KHAN

## Важно

Форма чүкө сейчас техническая. Финальная GLB/GLTF-модель заменит фабрику в `src/chuko.js` после подтверждения физики и управления. Положения финальной модели нужно откалибровать по её локальным осям.

## Запуск

Не открывать `index.html` двойным кликом. В папке проекта:

```bash
python -m http.server 8080
```

Открыть `http://localhost:8080`. Можно также использовать VS Code Live Server или Cloudflare Pages. Сборка не нужна.

Для этой версии интернет нужен для загрузки Babylon.js и Havok с CDN.

## Управление

1. Нажать `РАССЫПАТЬ`.
2. Дождаться остановки.
3. Нажать на обычный чүкө.
4. Подходящие цели того же положения подсветятся.
5. Нажать на цель либо сделать свайп в её сторону.

## Изменение v0.1.1

- Отключён автоматический reroll раскладки на этапе настройки физики.
- После одного рассыпания система ждёт стабилизации и сразу показывает положения.
- Валидатор пока работает только как диагностика и выводит причины неидеальной раскладки.
- Это сделано намеренно: сначала настраиваем естественное рассыпание, затем возвращаем незаметный reroll для игровых сценариев.

## v0.1.2-alpha

Исправления после первого браузерного теста:

- полностью отключён автоматический reroll: одно нажатие = одно рассыпание;
- яркая зелёная подсветка допустимых целей через Babylon HighlightLayer;
- выбранный чүкө выделяется золотым свечением;
- увеличена область рассыпания;
- исправлен picking по видимой оболочке чүкө;
- щелчок переведён на явную линейную скорость тела, чтобы движение было заметным и воспроизводимым;
- немного уменьшено трение для теста скольжения.


## v0.1.3-alpha

Исправление щелчка:

- видимая оболочка чүкө теперь кликабельна;
- выбранный чүкө выделяется золотым кольцом;
- допустимые цели выделяются яркими зелёными кольцами;
- щелчок больше не зависит от пробуждения sleeping rigid body;
- движение выполняется через Havok ANIMATED body, затем объект возвращается в DYNAMIC и физически ударяет цель.
